# TMeet mobile app (frontend)

Placeholder cho phần app mobile (오승화 + 바야라): onboarding UI, Figma screens, tích hợp OpenAI API (phân tích tính cách) và Google Maps API (bản đồ + pin).

Backend API mà app này sẽ gọi nằm ở `../backend` — xem README gốc để chạy backend local (`http://localhost:4000`).

Gợi ý stack (chưa chốt, nhóm tự quyết): Expo / React Native, để build ra APK/IPA như trong đề cương đề tài.
